### ⭐ Por que me contratar

- **Experiência real com dinheiro em movimento.** No dia a dia de adquirência, o que importa é não cobrar duas vezes, não perder transação e conseguir explicar cada centavo. Isso está nos meus projetos: idempotência, outbox, conciliação e auditoria.
- **Integração é a minha especialidade.** APIs de terceiros caem, mudam e limitam requisições. Construo com fila, retentativa e reprocessamento, para que uma falha vire um alerta e não um pedido perdido.
- **Padrão de empresa grande, tamanho de pequeno negócio.** Testes automatizados com cobertura mínima no build, CI/CD no GitHub Actions, Docker e README explicando cada decisão. Você recebe um sistema que outro desenvolvedor consegue manter.
- **Tecnologia atual.** Java 25, Spring Boot 4, Angular 22, Kafka, RabbitMQ, PostgreSQL, Terraform e AWS.

### 🤝 Como trabalho

1. **Conversa sobre o problema**: entendo o processo do seu negócio antes de falar de tecnologia.
2. **Proposta com escopo, prazo e valor fechados**, dividida em entregas pequenas.
3. **Entregas com demonstração**: você vê o sistema funcionando a cada etapa, não só no final.
4. **Código, documentação e acesso são seus**, com suporte combinado após a entrega.
